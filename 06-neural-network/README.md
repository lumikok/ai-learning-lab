# 两层网络：前向、反向与短训练

用 NumPy 实现两个输入、两个隐藏神经元、一个 sigmoid 输出的网络，追踪单样本梯度，再把逐样本梯度平均用于批量梯度下降。所有数据与初始参数均为手工给定；当前实验尚未进行 Iris 网络训练和验证集评价。

## 文件与运行

- `network_core.py`：复用的 sigmoid、单层前向、单样本反向与损失函数，计算函数只返回结果。
- `01-forward.py`：单样本/批量前向、隐藏层宽度变式、去隐藏激活的合并检查、数值梯度检查及一次更新。
- `02-training.py`：平均梯度、平均损失及 100 步全批量训练。`train_network` 返回四组训练后参数、`loss_history` 和 `p_history`，共六项。

在仓库根目录使用已有环境运行：

```powershell
uv sync --locked
uv run --frozen python .\06-neural-network\01-forward.py
uv run --frozen python .\06-neural-network\02-training.py
```

依赖 NumPy 2.4.3，与其他单元共用根目录环境；本单元没有新增依赖。这是本地机制实验，对应 MLS 第二门课前向、激活及计算图相关内容，不作为官方 Lab 完成记录。

## 命名与参数

样本按行存放，每一列权重对应一个神经元，`W` 的形状为“输入数 × 本层神经元数”。

| 名称 | 含义 | 原网络形状 |
|---|---|---|
| `W1、b1` | 第1层隐藏层的权重、偏置 | `(2,2)`、`(2,)` |
| `z1、a1` | 单样本隐藏层得分、激活值 | `(2,)` |
| `W2、b2` | 第2层输出层的权重、偏置 | `(2,1)`、`(1,)` |
| `z2、a2` | 单样本输出层得分、激活值 | `(1,)` |
| `Z1、A1、Z2、A2` | 对应的批量得分、激活值 | 前面增加样本维 |

`a1[1]` 是隐藏层第2个神经元的激活值，`a2` 是第2层的输出；最终概率取 `a2[0]`。`q = W1[1,1]`，梯度记为 `grad_q`；整组梯度 `dW1、db1、dW2、db2` 与对应参数形状一致。

原始参数为：

```python
W1 = np.array([[0.5, -1.0], [-0.25, 0.0]])
b1 = np.array([0.2, 0.0])
W2 = np.array([[1.0], [-2.0]])
b2 = np.array([0.0])
```

## 前向与非线性检查

输入 `[1,2]` 时，隐藏层得分为 `[0.2,-1]`，激活值约 `[0.549834,0.268941]`；最终得分约 `0.01195115`，概率 `0.50298775`。使用三条输入 `[[1,2],[0,0],[2,-1]]` 时，隐藏层/输出层形状为 `(3,2)`/`(3,1)`，第一条结果与单样本一致。

隐藏层改为三个神经元后，单样本隐藏输出为 `(3,)`、最终输出仍为 `(1,)`，示例概率 `0.60850339`，阈值 0.5 时判为 1。

去掉隐藏层激活、输出层仍保留 sigmoid 时，输出得分可合并为 `X @ (W1 @ W2) + (b1 @ W2 + b2)`。本例合并权重为 `[2.5,-0.25]`、偏置 0.2，两路三条预测的 `np.allclose` 为 True。隐藏层的非线性使多层模型能够超出这种单次线性得分加 sigmoid 的形式。

## 梯度与一次更新

取单样本 `[1,2]`、标签 1，其损失为 `-log(p)`。改变 q 时：

| q | 概率 | 损失 |
|---|---:|---:|
| -0.01 | 0.50494464 | 0.68330648 |
| 0 | 0.50298775 | 0.68718946 |
| 0.01 | 0.50101261 | 0.69112402 |

链式法则给出 `grad_q = (p-1) * W2[1,0] * a1[1] * (1-a1[1]) * x[1]`，约为 `0.390874154845394`。使用 `epsilon=1e-5` 的中心差分，数值梯度约 `0.390874154843068`，绝对差约 `2.33e-12`。学习率 0.1 时，单独更新 q 得到 `-0.03908742`，损失降至 `0.67230361`。

完整反向由输出得分梯度 `dz2 = a2-y` 开始，逐层乘局部变化率。代码另对 `W1[0,0]、b1[1]、W2[0,0]、b2[0]` 分别扰动检查；其他参数保持原值，四项梯度绝对差均小于 `1e-6`。使用同一组旧参数算出的四组梯度一起更新，损失 `0.68718946 → 0.62396505`，概率 `0.50298775 → 0.53581569`。

## 三样本平均梯度与 100 步训练

数据 `X=[[1,2],[0,0],[2,-1]]`，标签 `y=[1,0,1]`，仍用上面的初始参数。目标是三条交叉熵的平均值；每条样本用同一组参数计算梯度，累加后除以样本数，再更新一次。这是全批量梯度下降，逐条计算梯度只是实现方式。

学习率 0.1，一步平均损失 `0.54267342 → 0.53540200`；100 步结果为：

- 平均损失：`0.54267342 → 0.32424605`。
- 最终概率：`[0.78255410, 0.40516317, 0.81214387]`。
- `loss_history` 共 101 项，包含初始状态，全部为有限数。
- 使用实际返回的四组参数重新计算，损失和概率均与最后一条训练记录一致。

训练在参数副本上进行，返回值须对应实际更新的副本；仅日志下降不能证明调用方拿到了训练后的参数。当前结论是这组手工训练数据上的损失下降，没有验证集或泛化优势的证据。
