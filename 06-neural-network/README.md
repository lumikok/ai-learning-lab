# 两层网络：前向、反向与短训练

用 NumPy 实现两层 sigmoid 网络，先用手工小数据追踪前向、反向和梯度下降，再在 Iris 二分类中比较训练与验证表现。

## 文件与运行

- `network_core.py`：sigmoid、前向传播、单样本及批量梯度、损失和训练函数。
- `01-forward.py`：单样本/批量前向、隐藏层宽度变式、去隐藏激活的合并检查、数值梯度检查及一次更新。
- `02-training.py`：三样本平均梯度与 100 步全批量训练。`train_network` 返回四组训练后参数、`loss_history` 和 `p_history`，共六项。
- `03-iris-training.py`：随机初始化、Iris 训练与训练集/验证集评价。
- `04-learning-curves.py`：分别改变隐藏层宽度与训练样本数，比较损失并绘制学习曲线。
- `iris_data.py`：沿用 Iris 逻辑回归实验的标签映射和分层划分，提供原始划分及训练集标准化后的划分。

在仓库根目录使用已有环境运行：

```powershell

uv run --frozen python .\06-neural-network\01-forward.py
uv run --frozen python .\06-neural-network\02-training.py

uv run --frozen python .\06-neural-network\04-learning-curves.py
```

依赖 NumPy 2.4.3，Iris 加载和划分使用 scikit-learn，绘图使用 Matplotlib。04 入口输出对照表并打开图形窗口；无图形界面时可设置 `MPLBACKEND=Agg` 运行数值部分。版本由根目录锁文件管理。课程参考：MLS 第二门的前向传播、激活函数、计算图，以及 Week 3 的 Diagnosing bias and variance、Learning curves。

## 命名与参数

样本按行存放，每一列权重对应一个神经元，`W` 的形状为“输入数 × 本层神经元数”。

| 名称 | 含义 | 手工样例形状 |
|---|---|---|
| `W1、b1` | 第1层隐藏层的权重、偏置 | `(2,2)`、`(2,)` |
| `z1、a1` | 单样本隐藏层得分、激活值 | `(2,)` |
| `W2、b2` | 第2层输出层的权重、偏置 | `(2,1)`、`(1,)` |
| `z2、a2` | 单样本输出层得分、激活值 | `(1,)` |
| `Z1、A1、Z2、A2` | 对应的批量得分、激活值 | 前面增加样本维 |

`a1[1]` 是隐藏层第2个神经元的激活值，`a2` 是第2层的输出；最终概率取 `a2[0]`。`q = W1[1,1]`，梯度记为 `grad_q`；整组梯度 `dW1、db1、dW2、db2` 与对应参数形状一致。

原始参数为：

```python
W1 = np.array([[0.5, -1.0], [-0.25, 0.0]])
b1 = np.array([0.2, 0.0])
W2 = np.array([[1.0], [-2.0]])
b2 = np.array([0.0])
```

## 前向与非线性检查

输入 `[1,2]` 时，隐藏层得分为 `[0.2,-1]`，激活值约 `[0.549834,0.268941]`；最终得分约 `0.01195115`，概率 `0.50298775`。使用三条输入 `[[1,2],[0,0],[2,-1]]` 时，隐藏层/输出层形状为 `(3,2)`/`(3,1)`，第一条结果与单样本一致。

隐藏层改为三个神经元后，单样本隐藏输出为 `(3,)`、最终输出仍为 `(1,)`，示例概率 `0.60850339`，阈值 0.5 时判为 1。

去掉隐藏层激活、输出层仍保留 sigmoid 时，输出得分可合并为 `X @ (W1 @ W2) + (b1 @ W2 + b2)`。本例合并权重为 `[2.5,-0.25]`、偏置 0.2，两路三条预测的 `np.allclose` 为 True。隐藏层的非线性使多层模型能够超出这种单次线性得分加 sigmoid 的形式。

## 梯度与一次更新

取单样本 `[1,2]`、标签 1，其损失为 `-log(p)`。改变 q 时：

| q | 概率 | 损失 |
|---|---:|---:|
| -0.01 | 0.50494464 | 0.68330648 |
| 0 | 0.50298775 | 0.68718946 |
| 0.01 | 0.50101261 | 0.69112402 |

链式法则给出 `grad_q = (p-1) * W2[1,0] * a1[1] * (1-a1[1]) * x[1]`，约为 `0.390874154845394`。使用 `epsilon=1e-5` 的中心差分，数值梯度约 `0.390874154843068`，绝对差约 `2.33e-12`。学习率 0.1 时，单独更新 q 得到 `-0.03908742`，损失降至 `0.67230361`。

完整反向由输出得分梯度 `dz2 = a2-y` 开始，逐层乘局部变化率。代码另对 `W1[0,0]、b1[1]、W2[0,0]、b2[0]` 分别扰动检查；其他参数保持原值，四项梯度绝对差均小于 `1e-6`。使用同一组旧参数算出的四组梯度一起更新，损失 `0.68718946 → 0.62396505`，概率 `0.50298775 → 0.53581569`。

## 三样本平均梯度与 100 步训练

数据 `X=[[1,2],[0,0],[2,-1]]`，标签 `y=[1,0,1]`，仍用上面的初始参数。目标是三条交叉熵的平均值；每条样本用同一组参数计算梯度，累加后除以样本数，再更新一次。这是全批量梯度下降，逐条计算梯度只是实现方式。

学习率 0.1，一步平均损失 `0.54267342 → 0.53540200`；100 步结果为：

- 平均损失：`0.54267342 → 0.32424605`。
- 最终概率：`[0.78255410, 0.40516317, 0.81214387]`。
- `loss_history` 共 101 项，包含初始状态，全部为有限数。
- 使用实际返回的四组参数重新计算，损失和概率均与最后一条训练记录一致。

训练使用参数副本，并返回更新后的四组参数；评价时用返回参数重新计算损失和概率。

## Iris 训练与验证

数据和划分沿用[逻辑回归实验](../05-iris-classification/README.md)：保留 versicolor/virginica 两类，映射为 0/1，使用全部四项特征。固定划分种子 42，分层划分为 75 条训练样本、25 条验证样本；标准化的均值与标准差仅从训练集计算。

`load_iris_split()` 依次返回 `X_train、X_val、y_train、y_val`，形状为 `(75,4)、(25,4)、(75,)、(25,)`。按此顺序接收，特征数组与标签数组不能混用。

网络结构为 4→4→1，参数形状为 `W1(4,4)、b1(4,)、W2(4,1)、b2(1,)`。使用初始化种子 42，权重从均值 0、标准差 0.1 的正态分布抽取，偏置设为 0。同层神经元若具有完全相同的输入参数及输出连接，会得到相同激活与梯度；不同的随机权重用于打破这种对称性。

学习率 0.1，训练 1000 步，阈值为 0.5。1001 条损失均为有限数，返回模型重算的训练损失与最后一条训练记录一致。同一划分下，与四特征逻辑回归的结果比较如下：

| 指标 | 逻辑回归 | 两层网络 |
|---|---:|---:|
| 训练交叉熵 | 0.0749 | 0.0880 |
| 训练错误率 | 4% | 4% |
| 验证交叉熵 | 0.1652 | 0.1836 |
| 验证错误率 | 8% | 12% |
| 验证 FP / FN | 1 / 1 | 1 / 2 |

本次设置下，两层网络的训练错误率与逻辑回归相同，交叉熵和验证错误率更高。比较使用一次划分、一次网络初始化及固定步数；相同步数不保证不同模型已达到相同收敛程度，结果不能直接推广为模型的整体优劣。验证集用于开发阶段比较模型。

## 容量对照与学习曲线

`04-learning-curves.py` 使用 `load_iris_raw_split()` 获取未经标准化的同一份 75/25 划分，返回顺序仍为 `X_train、X_val、y_train、y_val`。每次实验仅用当前训练数据计算均值和标准差，再将同一变换用于训练集和固定验证集；不能先用全部 75 条拟合标准化，再截取小训练子集。

两组对照均使用两层 sigmoid、初始化种子 42、权重正态分布标准差 0.1、零偏置、学习率 0.1 和 1000 步全批量梯度下降，每组从头初始化，评价使用训练返回的更新后参数。

容量对照固定全部 75 条训练样本，只改变隐藏层宽度：

| 隐藏层宽度 | 训练交叉熵 | 验证交叉熵 |
|---|---:|---:|
| 4 | 0.087961 | 0.183596 |
| 8 | 0.075962 | 0.177778 |

本次增宽后两种损失都下降，但一次划分与初始化不足以证明越宽越好。两组最后 100 步的训练损失仍在下降，固定步数也不代表已经充分收敛。

样本量对照固定隐藏宽度 4：用种子 42 将 75 条训练样本的索引打乱一次，再取长度 25、50、75 的前缀；特征和标签使用相同索引，子集依次包含。验证集的原始样本、标签和评价指标保持不变；各组标准化后的验证数值可因训练统计量不同而变化。

| 训练样本数 | 训练交叉熵 | 验证交叉熵 |
|---|---:|---:|
| 25 | 0.0983 | 0.3367 |
| 50 | 0.1100 | 0.1933 |
| 75 | 0.0880 | 0.1836 |

学习曲线横轴为训练样本数，两条纵坐标序列分别记录每次训练完成后的平均训练、验证损失；`loss_history` 则描述同一模型随更新步数变化的损失。绘图直接使用实验返回值，线上的点对应实际测量，连线不表示已测量中间样本数。

本次验证损失的改善主要发生在 25→50 条（约 0.1435），50→75 条约改善 0.0097。可提出收集更多同任务训练数据、检验后续收益的假设，但三个点不能确定 75 条之后的走势，也不能单凭训练与验证的差距唯一判定原因。结果仅来自一次划分、一次子集顺序及固定训练设置；训练损失不必随样本量单调变化。新增训练数据不能通过挪用固定验证集获得，反复用于开发的验证集也不是独立最终测试集。
