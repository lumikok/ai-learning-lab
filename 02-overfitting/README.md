# 02｜过拟合与泛化

运行（AI 根目录）：`python .\02-overfitting\main.py`。

比较已确定的模型 A：`2*x`，B：`2*x+1-(x-2)**2`。这次只评价给定模型，未实现拟合多项式的训练算法。

训练数据 `[(1,2),(2,5),(3,6)]`，新数据 `[(1.5,3),(2.5,5),(4,8)]`。人为基础规律为 `y=2x`，第二条训练标签带有 +1 偏差。

| 模型 | 训练 MAE | 新数据 MAE |
|---|---:|---:|
| A | 1/3 | 0 |
| B | 0 | 1.5 |

用户手算训练 MAE 与 x=4 的误差正确；亲手实现预测函数和通用 MAE。初版 B 错写平方项前的加号，训练 MAE=4/3，与手算0不符；教师指出后用户修正，实际运行结果如表。

B 贴合训练偏差，训练成绩更好，新数据更差；不能只按训练误差选择模型。作文评分新场景中，用户选择验证 MAE 较低的 D，并解释 C 的训练好、验证差可能是过拟合。

这是一组人为对照，不能由此推出复杂模型一定更差，也不能将所有训练/新数据差异都归为过拟合。后续自然复验：在同一输入范围的新样本上观察模型比较，结合验证集与数据分布判断。
