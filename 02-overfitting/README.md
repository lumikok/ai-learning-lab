# 02｜过拟合与泛化

运行（仓库根目录）：`uv run --frozen python .\02-overfitting\main.py`。

对两个给定模型计算训练误差和新数据误差：A 为 `2*x`，B 为 `2*x+1-(x-2)**2`。

训练数据 `[(1,2),(2,5),(3,6)]`，新数据 `[(1.5,3),(2.5,5),(4,8)]`。人为基础规律为 `y=2x`，第二条训练标签带有 +1 偏差。

| 模型 | 训练 MAE | 新数据 MAE |
|---|---:|---:|
| A | 1/3 | 0 |
| B | 0 | 1.5 |

B 贴合训练数据中的偏差，训练误差更小，新数据误差却更大。选择模型时，需要观察验证数据上的表现，不能只比较训练误差。

易错点：B 的平方项前是减号。误写成加号时，训练 MAE 会变成 `4/3`，与目标表达式的结果不同。

这组构造数据展示了拟合训练偏差如何影响新数据误差；模型复杂度的作用还取决于数据规律、噪声与训练条件。
