## 预测与损失

先计算线性得分`z = X @ w + b`，再以`p = 1 / (1 + exp(-z))`得到标签为1的概率估计；`p >= threshold`决定是否预测为1。概率由模型参数决定，改变阈值不改变概率本身。

二元交叉熵是`-mean(y*log(p)+(1-y)*log(1-p))`，使用自然对数。标签为1时单样本损失为`-log(p)`，标签为0时为`-log(1-p)`：模型分配给真实类别的概率越低，损失越大。实现将概率裁剪到[1e-15,1-1e-15]以避免log(0)，因此边界处计算的是裁剪后的损失。

损失使用概率数组，分类错误使用阈值后的标签。误报FP是真实0、预测1，漏报FN是真实1、预测0。

## 实验结果与边界

五个输入为[-2,-0.5,0.2,0.5,2]，标签为[0,1,0,1,1]，固定w=[1]、b=0。概率约为[0.119203,0.377541,0.549834,0.622459,0.880797]，平均交叉熵为0.5000297719655501。

| 阈值 | 预测标签 | 错误总数 | FP | FN |
|---|---|---:|---:|---:|
| 0.5 | [0,0,1,1,1] | 2 | 1 | 1 |
| 0.7 | [0,0,0,0,1] | 2 | 0 | 2 |

在这两个候选中，提高阈值减少了误报、增加了漏报，错误总数相同；若漏报代价更高，更倾向0.5。不能据此说某个阈值普遍最好。两组使用相同概率，所以交叉熵相同；这也说明错误总数不足以描述错误类型及代价。

`01-prediction_and_loss.py` 是给定参数和构造数据上的计算与评价练习，不包含参数训练或独立测试集评估。课程对应吴恩达MLS第一门Week 3的Motivations、Logistic regression及后续分类损失内容；本地实验不作为官方Lab完成记录。

## 梯度与训练

`02-logistic_training.py` 复用相同的五样本与标签，从零权重和零偏置开始训练。对单个样本，计算链为权重→线性得分z→sigmoid概率p→交叉熵L；链式法则将沿途变化率相乘。

- sigmoid的导数为`dp/dz = p*(1-p)`。
- 标签为1时，`dL/dp = -1/p`，与sigmoid导数相乘得到`dL/dz = p-1`。
- 标签为0时，`dL/dp = 1/(1-p)`，相乘得到`dL/dz = p`。
- 合并为`dL/dz = p-y`，再乘对应特征，得到权重梯度。对样本取平均后，`dw = X.T @ (p-y) / m`，`db = mean(p-y)`。

每轮使用同组旧参数计算两个梯度再更新，损失记录包含初始状态；一步检查和1000步训练分别重置初始参数。学习率固定为0.1。

| 检查项 | 实际结果 |
|---|---|
| 初始概率 | 所有样本均为0.5 |
| 初始梯度 | dw=[-0.38]，db=-0.1 |
| 一步更新 | w=[0.038]，b=0.01；两者都增加 |
| 1000步参数 | w约[1.33708066]，b约0.54428821 |
| 交叉熵 | 0.69314718→0.46965220 |
| 阈值0.5的最终错误 | 2个，FP=1、FN=1 |

初始预测全为1；训练后前两个样本改为0，第一个由错变对，第二个由对变错，所以错误总数仍为2。错误数量相同不代表所有类别都没变化；交叉熵与错误数衡量的对象也不同。梯度和一步更新后的参数应分别核对，不能把b的新值0.01当成db。

## 决策边界与阈值

概率阈值为0.5时，边界满足`z=0`。一维模型的边界为`x=-b/w`；二维模型如`z=x1+x2-3`的边界为直线`x1+x2=3`。边界受特征表示、参数和阈值共同影响。

对于一维模型，令边界概率等于阈值t：`t=1/(1+exp(-z))`，得到`exp(-z)=(1-t)/t`，取自然对数并整理后，`z=log(t/(1-t))`。因此：

```text
x_boundary = (log(t/(1-t)) - b) / w
```

公式要求`0<t<1`且`w!=0`。本组权重为正，边界左侧预测0、右侧预测1，边界上沿用“概率大于等于阈值判1”的规则；负权重时两侧类别方向相反。

| 阈值 | 边界位置 | 边界±0.01处的概率 | 两侧预测 |
|---|---:|---|---|
| 0.5 | -0.40707209 | [0.49665735,0.50334265] | [0,1] |
| 0.7 | 0.22662032 | [0.69718464,0.70280034] | [0,1] |

选例检查不能只用远离边界的点。新输入-0.4069的得分约0.00023、概率约0.50005752，阈值0.5时应预测1；把得分直接与概率阈值比较会误判为0。所有分类判断均应使用概率与对应阈值比较。

当前结果仅说明构造训练数据上的更新、损失及边界检查正确，未进行训练/验证/测试划分或独立泛化评估。对应MLS第一门Week 3的Decision boundary、Cost function for logistic regression、Simplified Cost Function for Logistic Regression及Gradient Descent Implementation。
