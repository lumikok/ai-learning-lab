# Iris 二分类：基线、错误分析与特征对照

用 NumPy 逻辑回归区分 Iris 的 versicolor 与 virginica，比较四项特征和仅花瓣两项特征，并观察不同数据划分下的结果。训练核心沿用 `04-logistic-regression/02-logistic_training.py` 中的实现。

## 数据与运行

- 数据由 scikit-learn 的 [`load_iris`](https://scikit-learn.org/stable/modules/generated/sklearn.datasets.load_iris.html) 加载，随包内置，无需另行下载或复制 CSV。
- 原始标签 0（setosa）被排除；标签 1（versicolor）映射为 0，标签 2（virginica）映射为 1。筛选后共 100 条样本，两类各 50 条。
- 四列依次为萼片长度、萼片宽度、花瓣长度、花瓣宽度，单位为 cm；花瓣模型只取后两列。
- 实际复现环境：Python 3.14.2、NumPy 2.4.3、scikit-learn 1.9.1；依赖由根目录 `pyproject.toml` 与 `uv.lock` 管理。

在仓库根目录运行：

```powershell
uv sync --locked
uv run --frozen python .\05-iris-classification\main.py
```

脚本先打印种子 42 的数据检查、基线、两条错分记录与特征对照，再输出种子 0、1、2、42 的重复划分结果。

## 对照条件

- 使用 `train_test_split(test_size=0.25, stratify=y)`，每次训练 75 条、验证 25 条；同一种子下两组共用同一次划分。
- 每个划分仅用训练集计算逐列均值和标准差，对训练、验证应用同一变换。取标准化后的花瓣两列，等价于对原始花瓣两列用相应训练统计量单独标准化。
- 两组均从零权重、零偏置开始，学习率 0.1，训练 1000 步，分类规则为预测概率大于或等于 0.5 时判为 1。
- 评价交叉熵、错误率、FP、FN。FP 表示 versicolor 被判为 virginica，FN 表示 virginica 被判为 versicolor。
- 简单基线只根据训练集决定多数类。种子 42 下训练标签 0/1 数量为 37/38，故始终预测 1；验证标签 0/1 为 13/12，基线错误率为 13/25，即 52%。基线只报告分类指标，不比较其交叉熵。

对照假设：删除萼片特征可能因可用信息减少而提高错误率，同时用交叉熵观察概率预测的变化。

## 种子 42：训练与错误分析

| 指标 | 四特征 | 仅花瓣两特征 |
|---|---:|---:|
| 训练集交叉熵 | 0.0749 | 0.0787 |
| 训练集错误率 | 4% | 2.67% |
| 验证集交叉熵 | 0.1652 | 0.2309 |
| 验证集错误率 | 8% | 12% |
| 验证集 FP / FN | 1 / 1 | 1 / 2 |

四特征模型的两条错分如下。索引是当前验证数组中的位置，不是原始数据集编号。

| 验证集索引 | 四项原始测量值 | 真实标签 | 预测为 1 的概率 | 错误类型 |
|---|---|---:|---:|---|
| 2 | 4.9, 2.5, 4.5, 1.7 | 1 | 0.46765146 | FN |
| 22 | 5.9, 3.2, 4.8, 1.8 | 0 | 0.57288961 | FP |

两条记录在花瓣模型中仍错分，花瓣模型还多出一条 FN。花瓣模型训练错误率更低，但验证错误率更高；训练集分类错误更少不保证验证表现更好，交叉熵与错误率也不必同步变化。

零参数下另核对了偏置更新：`db = 0.5 - 38/75 = -0.00666667`，学习率 0.1 时一步后 `b = 0.00066667`。检查使用独立初始参数，不覆盖用于评价的训练模型。

## 更换划分的结果

每个种子重新从原始数据划分、拟合训练统计量并从零训练，不沿用上一组的参数或预处理统计量。下表中的数值按“四特征 / 花瓣两特征”排列。

| 随机种子 | 验证集交叉熵 | 验证集错误率 | 验证集 FP | 验证集 FN |
|---|---|---|---|---|
| 0 | 0.0393 / 0.0488 | 0% / 0% | 0 / 0 | 0 / 0 |
| 1 | 0.0567 / 0.0737 | 0% / 0% | 0 / 0 | 0 / 0 |
| 2 | 0.0827 / 0.0928 | 4% / 4% | 1 / 0 | 0 / 1 |
| 42 | 0.1652 / 0.2309 | 8% / 12% | 1 / 1 | 1 / 2 |

在这四次划分和相同训练设置下，四特征模型的验证集交叉熵均更低；错误率在三个划分中持平，仅种子 42 下更低。种子 2 下两组错误率相同，但 FP/FN 类型不同。

这些结果支持萼片特征在本实验中的额外价值，概率预测的改善体现为交叉熵更低。每个验证集只有 25 条，一条错分就改变 4 个百分点，且不同划分的验证样本可能重叠。结论限于这四次划分和给定的模型、训练设置。
