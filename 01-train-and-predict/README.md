# 01｜训练与预测

问题：固定模型 `预测耗时 = 3 × 距离 + b`，怎样从已有记录选择参数，并在未参与选择的数据上评分？预处理规则的数据来源会怎样改变结果？

在 AI 根目录运行：

```powershell
uv run --frozen python .\01-train-and-predict\main.py
```

## 实验结果

- 枚举整数 0～10，在训练集上选出 `b=5`，训练总绝对误差为 2。
- 训练记录为 `[(1,8),(2,12),(3,13)]`，测试记录为 `[(4,19),(5,22)]`；仅训练集选参数，测试平均绝对误差为 2.0 分钟。
- 用训练集最大距离 3 缩放，距离 3 变成 1；用全体最大距离 10 缩放则变成 0.3。
- 训练距离 `[1,2,3]`、测试距离 `[4,10]`：只从训练集确定除数 3，测试结果为 `4/3`、`10/3`；使用全体最大值 10 的版本作为信息泄漏对比。独立测试采用前者，超出 1 不要求重新拟合。

代码包含初始枚举、连续偏移、固定候选列表、独立测试和缩放对比。小数据直接写在脚本中。
