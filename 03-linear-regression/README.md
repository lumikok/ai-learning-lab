# 03｜单变量线性回归与梯度下降

问题：不预先给定最终参数，用训练数据学习 `w*x+b`，再用未参与训练的验证数据评价。

本实验为本地教学实验，对应吴恩达 Machine Learning Specialization 第一门 Week 1 的线性模型、损失函数与梯度下降；不记作完成官方 Lab 或已观看课程。

## 运行

在 AI 根目录运行：

```powershell
python .\03-linear-regression\main.py
```

只使用 Python 标准库。`predict` 预测，`cost` 计算 `sum((预测-y)**2)/(2*m)`，`gradients` 计算 `sum((预测-y)*x)/m` 和 `sum(预测-y)/m`。每轮用同一组旧参数计算两个梯度，再分别减去学习率乘梯度。

## 实际核查结果

第一组训练数据 `[(0,1),(1,3),(2,5),(3,7)]`，验证数据 `[(0.5,2),(2.5,6)]`。从 `w=1,b=1` 开始，学习率为 0.1。

- 初始损失 1.75，梯度 (-3.5,-1.5)。
- 一步后参数 (1.35,1.15)，损失约 0.604375。
- 重新从初始参数训练1000步，参数约 (2,1)，训练损失约 1.58e-28，验证MAE约 1.40e-14。

变式训练数据 `[(-1,4),(0,1),(1,-2),(2,-5)]`，验证数据 `[(-0.5,2.5),(1.5,-3.5)]`。用户运行前预测“w 会变负”。从 (0,0) 开始，学习率0.1，训练1000步后参数约 (-3,1)，训练损失约 1.85e-30，验证MAE约 1.78e-15。验证数据只评价，不参与梯度计算。

接近0的误差来自这两组人为线性小数据与浮点计算，不能据此认定真实任务会无误差或模型普遍泛化良好。

## 本次错误与帮助边界

- 手算梯度曾少一倍：平方求导产生的2抵消损失前的1/2，梯度除以m，不是2m；教师解释后代码正确。
- 初版只打印一步训练返回值，随后仍用旧参数计算损失；教师定位后，用户接收返回值并修正，1000步训练保留从初始参数重新开始。
- 公式、函数接口、初始数据及检查值由教师提供，用户实现关键代码；负斜率变式复用自己的函数并通过实际运行。未据此认定独立推导梯度或完成真实数据完整建模。

下一自然复验：学习率对照中预测并观察过大步长的损失变化，解释为何梯度方向正确也不保证任意步长都降低损失。
