# 03｜线性回归与梯度下降

用训练数据学习线性模型参数，从逐样本循环扩展到NumPy数组及多特征训练，并观察学习率、特征选择对结果的影响。

课程参考：吴恩达 Machine Learning Specialization 第一门 Week 1 的线性模型、损失与梯度下降，以及 Week 2 的向量化、多特征训练与特征缩放。

## 运行

在 AI 根目录运行：

```powershell
uv sync --locked
uv run --frozen python .\03-linear-regression\01-loop_linear_regression.py
uv run --frozen python .\03-linear-regression\02-numpy_linear_regression.py
uv run --frozen python .\03-linear-regression\03-multiple_linear_regression.py
uv run --frozen python .\03-linear-regression\04-feature_scaling.py
```

`01-loop_linear_regression.py` 只使用 Python 标准库；其余程序使用仓库统一环境中的 NumPy。下面先说明循环版。`predict` 预测，`cost` 计算 `sum((预测-y)**2)/(2*m)`，`gradients` 计算 `sum((预测-y)*x)/m` 和 `sum(预测-y)/m`。每轮用同一组旧参数计算两个梯度，再分别减去学习率乘梯度。

## 实验结果

第一组训练数据 `[(0,1),(1,3),(2,5),(3,7)]`，验证数据 `[(0.5,2),(2.5,6)]`。从 `w=1,b=1` 开始，学习率为 0.1。

- 初始损失 1.75，梯度 (-3.5,-1.5)。
- 一步后参数 (1.35,1.15)，损失约 0.604375。
- 重新从初始参数训练1000步，参数约 (2,1)，训练损失约 1.58e-28，验证MAE约 1.40e-14。

变式训练数据 `[(-1,4),(0,1),(1,-2),(2,-5)]`，验证数据 `[(-0.5,2.5),(1.5,-3.5)]`。从 (0,0) 开始，学习率0.1，训练1000步后参数约 (-3,1)，训练损失约 1.85e-30，验证MAE约 1.78e-15。验证数据只评价，不参与梯度计算。

接近0的误差来自这两组人为线性小数据与浮点计算，不能据此认定真实任务会无误差或模型普遍泛化良好。

## 易错点

- 平方求导产生的2抵消损失前的1/2，梯度除以m，不是2m。
- 评价训练后损失时接收并使用训练函数返回的参数；比较不同训练步数或学习率时，每组重新设置初始参数。

## 学习率对照

保持原训练数据、初始参数(1,1)和20步更新不变，只改变学习率。每组记录更新前的第0步及每次更新后的损失，共21个值。

| 学习率 | 第0步损失 | 第1步 | 第20步 |
|---|---:|---:|---:|
| 0.01 | 1.75 | 1.608044 | 0.333138 |
| 0.1 | 1.75 | 0.604375 | 0.007996 |
| 1.0 | 1.75 | 17.687500 | 2.859242e20 |
| 0.5 | 1.75 | 2.109375 | 81.710196 |

本实验中0.01和0.1的损失下降，0.1在相同步数下下降更多；1.0和0.5发散，减到0.5只是减慢发散，并未稳定。负梯度给出当前位置的局部下降方向，步长过大仍可能增加损失；跨过低点本身不代表发散，须看后续变化。稳定步长依赖数据与损失，不能将本实验数值当作所有任务的阈值。

## 数组梯度与训练

`02-numpy_linear_regression.py` 将单变量回归的损失与梯度改为数组计算，保留迭代更新参数的循环。x、y和残差均取一维(m,)；两个梯度用同组旧参数计算，再更新w、b。

- 原数据初始J=1.75，梯度(-3.5,-1.5)，一步参数(1.35,1.15)；与循环版比较，梯度及1/1000步参数在1e-10容差内一致。
- 新数据[(-2,5),(0,1),(1,-1)]从(0,0)以学习率0.1训练1000步，得到约(-2,1)，J约1.51e-30。评价训练后损失必须接收训练函数返回的新参数，不能仍使用初始值。
- 多特征预测示例：X形状(3,2)、w形状(2,)，用X @ w+b得到[10,5,3]，输出形状(3,)；该文件只做多特征预测，参数训练见下一节。

一维残差与输入的点积表示逐元素乘积的求和。(m,)与(m,1)相减会广播成(m,m)，可能不报错却改变计算含义；比较损失前先确认每个样本对应一个残差。

## 多特征线性回归训练

`03-multiple_linear_regression.py` 使用X(m,n)、w(n,)和y(m,)，预测及残差均为(m,)。每个权重的梯度是残差乘对应特征列后取平均，合并为`dw = X.T @ e / m`；偏置梯度为残差均值。每轮用同组旧参数计算全部梯度后更新，样本数在函数内从传入的y计算。

以学习率0.1训练1000步，脚本包含以下对照：

| 数据/对照 | 结果 |
|---|---|
| 四样本、两特征 | 初始J=1.75，dw=[-1.25,-0.5]、db=-1.5；训练后w约[2,-1]、b约1，J约1.46e-17 |
| 同一数据仅保留第一列 | 训练后w约[2]、b约0.5，J=0.125；删列后相同输入对应不同标签，继续训练无法同时拟合 |
| 五样本、两特征新数据 | 从零参数训练得到w约[-2,3]、b约2，J约7.10e-30；新输入[2,-1]预测约-5 |
| 之前的单变量数据改为X(4,1) | 初始J=1.75，dw=[-3.5]、db=-1.5；一步更新得到w=[1.35]、b=1.15，与单变量实现一致 |

这些构造数据用于检查多特征训练与单变量公式的一致性；特征缩放对训练过程的影响见下面的标准化对照。

## 标准化与损失过程对照

`04-feature_scaling.py` 只用训练集按列计算均值和标准差，以`(X-mu)/sigma`标准化；新样本沿用训练统计量，且使用在标准化输入上训练的参数预测。标准化不会使任意分布变为正态分布，结果也不保证落在[-1,1]。

两组使用相同五样本与标签、零权重/零偏置、学习率0.1和40步更新，仅改变输入是否标准化。零参数使两组初始预测相同；每组记录含第0步的41个损失。

| 观察量 | 原始输入 | 标准化输入 |
|---|---:|---:|
| 初始损失 | 5.1 | 5.1 |
| 第1步损失 | 11948.33384 | 4.252502 |
| 第20步损失 | 4.166196e109 | 0.165491 |
| 第40步损失 | 5.214340e220 | 0.007187 |
| 首次达到J<0.01 | 40步内未达到 | 第38步 |

训练均值为[20,0.2]，标准差约[74.833148,0.748331]；新样本[200,-1]标准化后约[2.405351,-1.603567]，用第40步参数预测约-4.646771。

本设置下原始组发散，标准化组稳定下降；这不表示原始输入在更合适的学习率下也无法训练，也不能据此判断标准化后泛化更强。达到损失阈值不等于完全收敛，相邻损失变化小也不是已到最优点的充分证据。课程对应MLS第一门Week 2的Feature scaling part 1/2与Checking gradient descent for convergence。
